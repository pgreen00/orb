Orb styles the HTML you already write, so links, tables, and lists look right without a component. When you need more, its design tokens and utility classes let you build your own pages with the same colors, type, and spacing, in light and dark mode.

Start with the element. Add a class or a token only when the element doesn't already do what you need. To add Orb's styles to a page, see [Installation](../../installation/).
